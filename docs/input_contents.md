[1차 심의 워크플로우] 전용 State 명세
목적: 사용자가 입력한 콘텐츠(텍스트, 이미지, pdf 등)를 분석하고, 관련 법령을 선별하여, AI 심의 및 자체 검증(Evaluation)을 통과하는 것까지 담당합니다.

# 사용자가 입력해 줄 내용
입력 텍스트: 사용자가 최초로 제출한 원본 글이나 광고 문구 내용입니다.

입력 파일: 사용자가 최초로 제출한 이미지/ pdf / docx / hwp 입니다.

채널: 홈페이지/sns/문자, 카카오톡/기타

컨텐츠 유형: 금융상품 광고, 업무광고(브랜드, 서비스 광고 등), 정보제공(상품 안내 등),기타

(상품 광고인 경우) 상품군: 예금성, 대출성, 카드/혜택, 자동차금융, 투자성, 예금자보호, 기타

업권: 은행, 여신금융, 금융투자, 저축은행, 기타

언어(외국어 콘텐츠인 경우): 한국어/영어/필리핀어/캄보디아어/중국어/베트남어/

# Agent workflow 과정에서 채워야 할 내용
OCR 추출 텍스트: OCR 노드가 입력 파일에서 판독해 낸 글자 데이터입니다. 이후 RAG와 심의 노드의 입력으로 결합됩니다.

관련 법령 리스트: RAG 노드가 현재 콘텐츠와 매칭하여 찾아낸 구체적인 법률 조항이나 심의 규정 모음입니다.

체크리스트: 입력 내용과 관련 법령 기준으로 LLM이 생성한 심의 생성 및 평가를 위한 가이드라인 체크리스트.

1차 심의 결과서: LLM 또는 VLM 심의 노드가 법령을 기반으로 초안 작성한 심의 의견 내용입니다.

평가 점수 및 피드백: 평가자 노드가 심의 결과를 검증한 점수와 미달 시 보완을 요구하는 구체적인 가이드 문구입니다.

재심의 카운터(Loop Count): 평가 미달로 인해 내부 루프를 돈 횟수입니다. (무한 루프 방지용 안전장치)

1차 심의 대화 로그: 1차 워크플로우 내 노드들이 주고받은 메시지 히스토리입니다.
